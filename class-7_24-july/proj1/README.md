# Portfolio — Sajid Khan Afridi

Plain HTML/CSS/JS portfolio site. No build tools, no dependencies —
just open `index.html` in a browser.

## How to view

Double-click `index.html`, or open it in a browser directly. No server
or Node.js required.

## What to edit

Look for `<!-- EDIT: ... -->` comments in `index.html` — they mark every
placeholder:

- **Hire Me / LinkedIn links** — replace the `#` hrefs on the navbar,
  hero, and contact buttons with your real LinkedIn profile URL.
- **GitHub link** — replace the `#` href in the Contact section.
- **Bio & stats** — About section text and the `data-target` numbers on
  the stat cards (students taught, batches, years).
- **Projects** — each card's title, description, tags, and links in the
  Projects section.
- **Project images** — `assets/project-placeholder-1.jpg`,
  `-2.jpg`, `-3.jpg` don't exist yet; drop your own images into
  `assets/` using those filenames (or update the `src` attributes to
  match whatever you name them).

Your profile photo is already in place at `assets/profile.jpg`.

## Files

- `index.html` — page structure and content
- `styles.css` — theme, layout, animations
- `script.js` — scroll-reveal, mobile nav, rotating role text, stat
  counters
- `assets/` — images (profile photo + project images you add)
